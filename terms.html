이용 안내

시행일: 2026년 6월 11일

Twincap GitHub Pages 사이트는 개인 개발 프로젝트를 소개하고 제작 과정을 기록하기 위한 포트폴리오입니다. 방문자는 프로젝트 설명을 읽고 GitHub 저장소로 이동해 소스 코드와 변경 이력을 확인할 수 있습니다.

콘텐츠의 성격

이 사이트의 글은 프로젝트 소개와 학습 기록을 목적으로 작성되었습니다. 각 저장소의 소스 코드, 라이선스, 실행 방법은 해당 GitHub 저장소의 안내를 우선합니다. 이 사이트의 제작 노트는 저장소를 그대로 복사한 문서가 아니라 프로젝트의 의도와 개선 방향을 설명하는 독립 콘텐츠입니다.

책임의 범위

공개 저장소와 데모는 예고 없이 수정되거나 중단될 수 있습니다. 학습용 코드와 실험 프로젝트는 특정 환경에서만 정상적으로 동작할 수 있으므로, 실제 사용 전 저장소 설명과 코드를 직접 확인해 주세요.

광고 운영 기준

현재 이 사이트는 광고 코드를 배치하지 않은 상태로 콘텐츠를 정비하고 있습니다. 향후 광고를 사용하더라도 준비 중인 화면, 오류 화면, 이동 전용 화면, 본문이 부족한 도구 화면, 사용자의 클릭 위치와 가까운 영역에는 광고를 배치하지 않습니다. 광고가 표시되는 경우에도 본문보다 더 두드러지게 보이거나 광고 클릭을 유도하는 문구는 사용하지 않습니다.

문의

오류 제보와 개선 제안은 twincap.github.io 저장소 이슈 에 남길 수 있습니다.
