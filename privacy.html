개인정보처리방침

시행일: 2026년 6월 11일

Twincap GitHub Pages 사이트는 공개 프로젝트와 GitHub 저장소 설명을 소개하는 정적 웹사이트입니다. 현재 이 사이트는 회원가입, 로그인, 결제 기능을 제공하지 않으며 방문자의 이름, 전화번호, 주소 같은 직접 식별 정보를 자체적으로 수집하지 않습니다.

수집될 수 있는 정보

GitHub Pages, 브라우저, 외부 링크 이동 과정에서 접속 일시, 브라우저 정보, 참조 URL, IP 주소 등 일반적인 로그 정보가 서비스 제공자 또는 방문자의 브라우저 환경에 의해 처리될 수 있습니다. 문의를 위해 GitHub 이슈를 남기는 경우 사용자가 공개한 GitHub 계정명과 작성 내용이 GitHub에 공개될 수 있습니다.

정보 이용 목적

  • 사이트의 정상적인 표시와 보안 유지
  • 프로젝트 문의, 오류 제보, 개선 제안 확인
  • 콘텐츠 구성과 링크 구조를 개선하기 위한 운영 참고

Google AdSense와 쿠키

현재 이 사이트의 코드에는 Google AdSense 광고 스크립트나 광고 단위를 배치하지 않았습니다. 향후 Google AdSense를 사용할 경우 Google을 포함한 제3자 광고 제공자는 쿠키 또는 유사한 기술을 사용해 사용자의 이 사이트 및 다른 사이트 방문 기록을 기반으로 광고를 제공할 수 있습니다.

사용자는 Google 광고 설정 페이지에서 개인 맞춤 광고를 관리하거나 해제할 수 있습니다. 광고와 쿠키에 대한 자세한 내용은 Google 개인정보처리방침, Google 광고 설정, Digital Advertising Alliance 선택 도구 에서 확인할 수 있습니다.

외부 사이트 링크

이 사이트는 GitHub 저장소, GitHub 프로필 등 외부 사이트로 이동하는 링크를 포함합니다. 외부 사이트의 개인정보 처리와 운영 정책은 해당 사이트의 정책을 따릅니다.

보관과 삭제

이 사이트는 자체 데이터베이스를 운영하지 않습니다. GitHub 이슈나 외부 서비스에 공개한 내용의 수정 또는 삭제가 필요한 경우 해당 서비스에서 제공하는 기능을 이용하거나 GitHub 프로필을 통해 문의해 주세요.
